# secgin lessons

Generalized lessons from past audits, appended by the host agent when the operator asks. See "Long-term memory with Supermemory" in [SKILL.md](SKILL.md). Read before planning a run.

Rules: no source code, secrets, private hosts, or undisclosed target names. Outcome is what the operator reproduced, never model output alone.

Entry format:

```
## <date> <web2|web3|ai> <stack> - <bug class>
- Found by: <hunt cell / invariant>
- Outcome: reproduced | false-positive | unknown
- Lesson: <what to do differently>
```
